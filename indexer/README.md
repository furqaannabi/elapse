# Indexer — Envio HyperIndex on Monad

Watches every `AccrualStream` clone the `StreamFactory` spawns and POSTs each lifecycle log to
**our** platform ingest URL (`POST /internal/ingest`), never to a Merchant. The indexer holds one
secret, the ingest token; it never sees Merchant keys or webhook secrets. Merchant webhooks are
signed and retried by the worker in `api/src/worker/`.

Spec: [`docs/specs/indexer-frd.md`](../docs/specs/indexer-frd.md) (signed 2026-09-05).
Decisions: [`docs/decisions/2026-09-05-indexer-hosting-reorg-transport.md`](../docs/decisions/2026-09-05-indexer-hosting-reorg-transport.md).

## Bounty note (Envio, doc §11)

HyperIndex + the Effect API is the canonical stream → event ingest for Elapse. HyperSync reads
Monad (chain 10143 now, 143 in Week 5) with no RPC polling; `StreamCreated` registers each clone
dynamically; every handler awaits the `postIngest` Effect (`cache: false`, `rateLimit: false`),
which delivers one log per POST to the platform. The signed, retried, secret-rotated hop to the
Merchant is ours, downstream of ingest.

## Setup

```sh
cd indexer
pnpm install --ignore-workspace     # standalone package: Envio Cloud builds from this folder alone
cp .env.example .env                # ENVIO_API_TOKEN (free at envio.dev/app/api-tokens), ENVIO_INGEST_URL, ENVIO_INGEST_TOKEN
pnpm sync-abi                       # copies ABIs + deployments/<chainId>.json from contracts/ (run forge build first)
pnpm codegen                        # regenerates .envio/ types after config.yaml or schema.graphql change
pnpm test                           # 21 tests, no network
pnpm dev                            # local Postgres + Hasura in Docker, syncs testnet from the factory block
```

`pnpm dev` serves GraphQL at `http://localhost:8080/v1/graphql` (Hasura console password `testing`).
Local `.env` values (`ENVIO_INGEST_URL=http://localhost:4000/internal/ingest`) point at the API in `api/`.

## Layout

| Path | Purpose |
| --- | --- |
| `config.yaml` | Chain 10143, `start_block` = factory deployment block, `StreamFactory` fixed + `AccrualStream` dynamic, `address_format: lowercase`, `rollback_on_reorg: false` |
| `schema.graphql` | `Stream`, `StreamEvent`, `Settlement`, `Factory`, `LedgerEntry` (FR-IDX-010..014) |
| `src/handlers/StreamFactory.ts` | `StreamCreated` (register clone, create `Stream`, `Factory.streamCount++`), `FeeChanged` |
| `src/handlers/AccrualStream.ts` | `Deposited`, `StreamStarted`, `StreamPaused`, `StreamResumed`, `Settled`, `StreamCanceled` — pure state transitions + ledger rows |
| `src/lib/record.ts` | Per-log bookkeeping: `StreamEvent`, `LedgerEntry`, ingest call, ingest status |
| `src/effects.ts` | `postIngest` Effect: 3 retries (1 s, 4 s, 16 s) on 5xx/network, fail fast on 4xx, never throws |
| `src/lib/deployments.ts` | Seeds `Factory` fee/treasury from `deployments/<chainId>.json` (the constructor emits no `FeeChanged`) |
| `abis/`, `deployments/` | Generated by `pnpm sync-abi`; never hand-edited |
| `test/` | Vitest with `createTestIndexer` + simulated logs; a fake `fetch` stands in for ingest |

## Ingest body (API FR-API-070)

```json
{
  "chain_id": 10143, "block_number": 59877161, "block_hash": "0x…", "block_timestamp": 1757000220,
  "tx_hash": "0x…", "log_index": 1, "address": "0x86776c5b…", "event_name": "StreamCanceled",
  "args": { "at": "1757000220", "secondsElapsed": "220", "amountSettled": "880000", "amountRefunded": "13520000" },
  "ledger": [{ "kind": "refund", "amount": "13520000", "from": "0x86776c5b…", "to": "0x2222…" }]
}
```

`uint256` values are decimal strings, addresses lowercase. The platform is idempotent on
`(chain_id, tx_hash, log_index)`; the indexer may send any log any number of times (Envio's
preload runs handlers twice, and `context.effect` dedupes the call within a run).

Ledger derivation: `Deposited` → `deposit`; `Settled` → `settlement` (`amount − fee`, to merchant)
and `fee` (to treasury, omitted when zero); `StreamCanceled` → `refund` (`amountRefunded`, omitted
when zero). A cap end is an ordinary `StreamCanceled` with `secondsElapsed == maxEscrow / rate`.

## Reorgs

`rollback_on_reorg: false` (ADR 2026-09-05). MonadBFT finality makes a post-ingest reorg a chain
failure, not a normal path. Every row and every ingest carries `block_hash` so the platform can
audit and reverse by hand (FR-IDX-033) until the Week 4 `reconcile` script exists.
