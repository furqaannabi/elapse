Compute you pay for by the second.

Write JavaScript, run it on real AWS Lambda, and pay for the seconds your session is open — not per month, not per request, not rounded up to the hour.

How it works

  1. Write JavaScript in the console. Editing is free and takes as long as you like.
  2. Press Run. That is what opens the meter, and it runs from that second.
  3. Press End when you are done. You pay for the seconds it was open, and the rest of your deposit comes back.

Opening the console charges nothing, and nothing on this page is metered. Your first Run is what starts a real meter.

What Northwind runs

A sandboxed Node runtime on real AWS Lambda. fetch, node builtins via require, and anything you can write in a function body. Results come back with the Lambda's own duration, so you can see what you are paying for.

{{merchant}} ends your meter when you close the tab, because you are paying for compute. A subscription meant to outlive the tab simply never calls cancel — that is the merchant's choice, not a rule of the billing.
